# Changelog

- First release of **Studying with Claude**.
- On/off toggle that persists for the conversation.
- Socratic prompts, hint ladder and self-reflection questions.
- Scaffolded lessons with roadmaps and layered explanations.

- Homework and writing-assignment guardrails.
- Support for notes, slides, PDFs, syllabi and photos of problems.
- Study plans, timed reviews, quizzes and flashcards.
- Pace and level adjustment, memory personalization, visuals and voice.
- Claude Code plugin and marketplace manifests.
